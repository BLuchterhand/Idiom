# Security Policy

## Reporting

Please report security issues privately before public disclosure. If the GitHub
repository security advisory flow is unavailable, contact the maintainer through
the repository owner profile.

## Supported Versions

Public source release support begins with the first tagged release. Until then,
`main` should be treated as pre-release software.

## Secret Handling

Do not open issues or pull requests containing real API keys, private model
paths, customer data, transcripts, telemetry excerpts, or local audit bundles.
Use sanitized reproduction steps and synthetic fixtures.
