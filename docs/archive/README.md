# Documentation Archive

This directory holds historical Idiom documents that are useful as evidence but
are no longer the live source of guidance.

Archived documents usually fall into one of these categories:

- completed implementation trackers or review logs
- superseded design sketches or migration plans
- landed one-off integration handoff snippets
- historical parity, extraction, or release-prep notes

Live implementation and design work should start from:

- [../idiom-design-roadmap.md](../idiom-design-roadmap.md)
- [../decisioning-north-star.md](../decisioning-north-star.md)
- [../idiom-maintenance-best-practices.md](../idiom-maintenance-best-practices.md)
- [../design-harness-optimization-program.md](../design-harness-optimization-program.md)

Do not treat archived docs as current authority unless a live design links to a
specific archived section as historical rationale.
