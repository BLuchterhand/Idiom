## Schema

- `review_status`: whether the row was generated by automated triage, explicit reviewer classification, or tracker self-review.
- `dead_unused_signal`: concrete deadcode/reviewer signal, or an explicit not-detected result for the current scan.
- `duplicate_signal`: name-level duplicate signal only; semantic duplicate removal requires follow-up source review.
- `decision`: retain, delete-safe symbols, compatibility retention, or future rearchitecture candidate.
- `action_taken`: the explicit action for that file in this pass.
