# Agent Harness Obsidian Export

This directory is a self-contained export bundle for the Agent Harness documentation
vault.

Open `docs/obsidian` as an Obsidian vault, then start with
`00 - Home.md` or `22 - Ground-Up Implementation Plan.md`.

## Layout

- `docs/obsidian/`: copied Obsidian-ready notes.
- `docs/`: companion design docs that make the vault useful outside the source
  repository.
- `EXPORT_MANIFEST.md`: included files and selection rationale.

## Recommended Reading

For a rebuild or work-project adaptation:

1. `docs/obsidian/22 - Ground-Up Implementation Plan.md`
2. `docs/harness-strategic-thesis.md`
3. `docs/harness-design-roadmap.md`
4. `docs/decisioning-north-star.md`
5. The seven pillar design docs listed in `EXPORT_MANIFEST.md`
6. `docs/obsidian/15 - Glossary.md`

The export intentionally excludes source-repository release notes, tactical
patch plans, proof fixtures, and one-off validation reports. It is intended as a
portable guideline pack, not a snapshot of one implementation history.
